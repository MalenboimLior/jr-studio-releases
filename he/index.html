הודעה חשובה לבטא של Windows

מתקין Windows עדיין אינו חתום דיגיטלית. Windows עשוי להציג “Windows protected your PC”, לזהות מפרסם לא ידוע או לחסום את האפליקציה באמצעות Smart App Control. יש להתקין רק אם סומכים על הורדת הבטא המוזמנת מ־getjr.app, ולאמת אותה מול סכום הבדיקה של הגרסה.

  1. מורידיםבוחרים את קובץ ההתקנה וקוראים את אזהרת Windows למעלה.
  2. מתקיניםפותחים DMG חתום ב־Mac או קובץ בטא ‎.exe לא־חתום ב־Windows.
  3. יוצריםפותחים, בוחרים נקודת פתיחה ומתחילים לבנות.

זוהי גרסת בטא בהזמנה בלבד. יש להתקין אותה רק אם הוזמנתם לבדוק את Jr. Studio. Jr. יכול להכין דוח בטא מקומי, אך הוא יוצא מהמחשב רק אחרי שבודקים ומשתפים אותו.
